# 🏢 SP Coworking Spacefinder

## 📝 Project Description
A platform to discover and book coworking spaces. Developed using C (Structured Programming) as a practical assignment.

## 🛠️ Technologies Used
- C Language (Structured Programming)
- Git & GitHub

## ✨ Key Features
- Search for workspaces by location and price.
- View space details.
- Simple booking system.
